Design the email. Send it with one call.

Email Platform keeps your email templates and sends your email. Build each one in a visual designer, share a header and footer between them, then send from any app by its slug, through the SMTP provider you already use. Every email is logged.

Features

Everything an app needs to send email well

Every email, logged. Its status, the rendered email and any error from the provider, searchable, and kept as long as you choose.

Every send is retried

3 times

with backoff before a clear failure. Repeat a request safely with an Idempotency-Key.

Light and dark previews. See your email the way mail apps that darken emails will show it.

27 social networks, built in. Icons written into the email as SVG, with nothing to host.

Send by slug. A name your code can keep: lowercase letters, numbers and hyphens, unique to each template.

Built-in emails

Start from 15 emails that are ready

Sign-ups, password resets, passkeys, invitations and account changes, written in plain English with a shared Wizzaroo header and footer. Add them in one command, then make them yours in the designer.

  • Text, buttons, images, columns, dividers, socials and HTML
  • Headers and footers edited once, used everywhere
  • A shared from address for each set of templates
  • Desktop and phone previews, in light and dark

Sending

Send from any app

Send a template by its slug with its variables. HTML-escaping, the plain-text part, the from address, retries and the log are taken care of.

  • To, cc, bcc, reply-to and attachments
  • Required variables checked before sending
  • Retries with backoff, then a clear failure
  • Amazon SES, Postmark, Fastmail, Gmail or any SMTP provider

From Node, use the typed client, @adrianeyre/email-client, published to GitHub Packages. Point the @adrianeyre scope at GitHub Packages in an .npmrc beside your app's package.json, with a GitHub token that has the read:packages scope, then run pnpm add @adrianeyre/email-client. The built-in emails' variables are checked when you compile.

curl 
curl -X POST https://mail.example.com/v1/messages \
  -H "Authorization: Bearer ek_…" \
  -H "Content-Type: application/json" \
  -d '{"to":["ada@example.com"],
       "templateSlug":"wizzaroo-reset-your-password",
       "variables":{"email":"ada@example.com",
         "resetUrl":"https://app.example.com/reset?t=…",
         "linkLifetime":"1 hour"}}'
.npmrc 
@adrianeyre:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
Node 
import { createEmailClient } from "@adrianeyre/email-client";

const email = createEmailClient({
  baseUrl: "https://mail.example.com",
  apiKey: process.env.EMAIL_API_KEY,
});

await email.builtIn.resetYourPassword({
  to: "ada@example.com",
  variables: { email: "ada@example.com", resetUrl, linkLifetime: "1 hour" },
});

Get started

Running in minutes

  1. Run it

    pnpm install
docker compose -f docker-compose.dev.yml up -d
pnpm migrate
pnpm exec vite build
pnpm run:local api

  2. Sign in and connect SMTP

    pnpm cli user:create you@example.com
open http://localhost:4320

    Set your SMTP provider on the Delivery page.

  3. Add templates and send

    pnpm cli templates:add-built-ins
pnpm cli apikey:create "My app"

    Then send by slug with the API key from your app.
